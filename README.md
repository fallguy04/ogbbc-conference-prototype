# Annual Conference prototype

A working prototype of the Annual Conference tools for ogbbc.org, as a WordPress plugin, for the
webmasters and the Committee of Arrangements to look at. Every person, household and number in it is
made up. It is not the real site.

**Open it:** the link below runs it in your own browser through WordPress Playground (WordPress.org's
own tool). Nothing is installed, and what you click stays in your browser.

https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/fallguy04/ogbbc-conference-prototype/main/blueprint.json
